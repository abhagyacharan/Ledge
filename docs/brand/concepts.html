Ledge logo concepts

Four marks drawn on a 32-unit grid. Each icon's L is the same height as the capital L in the wordmark (Bricolage Grotesque semi-bold, outlined), so in the lockup the two Ls match. Left: ink on light. Right: light on the cover green-black. The second lockup in each half shows the one orange detail.

Chosen: B, the bottom line (O, 2026-11-12). The finished logo is in logo.html; the SVG files for the other concepts were removed from public/brand/ and live only on this page.

Claude's recommendation was A, the shelf. It is the only one that draws the name itself (a ledge, with something set down on it), it stays an L at 16px, and its one orange square fits the app's one-orange rule.

A · The shelf

  • A place to set things down
  • A foothold

The L is a wall with a ledge sticking out of it, and something small has been set down on the ledge: a task, an entry, a thought you no longer have to carry. It reads as an L first and as a picture second.

App icon

B · The bottom line

  • Ledger
  • Exact numbers

An L standing on the accountant's double rule, the two lines drawn under a final total. It refines today's placeholder: equal weights, equal gaps, every edge on the pixel grid so it stays sharp at 16px.

App icon

C · The foothold

  • A foothold
  • Steady progress

From the foot of the L, two small footholds climb up and to the right, one step at a time, like holds on a rock face or entries filling a page. The orange version marks the highest hold: how far you have got.

App icon

D · The set square

  • Exact numbers
  • A ledge (bracket)

An L closed by a diagonal becomes a set square, the drafting tool for exact right angles, and also a shelf bracket, the thing that holds a ledge up. The wildcard: precision and support in one shape.
