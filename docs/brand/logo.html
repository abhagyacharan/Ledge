Ledge logo: the bottom line

An L standing on the double rule an accountant draws under a final total: the bottom line, settled and correct. Every edge sits on a 32-unit grid in steps of 4, so at 16px each bar is exactly 2 pixels and nothing blurs. The icon's L is as tall as the capital L of the wordmark (Bricolage Grotesque, weight 600, outlined).

Lockup

The orange second rule is the default everywhere (O, 2026-11-12). The one-colour version is only for places that cannot show orange, such as one-colour printing.

Construction

One stroke, s, is 4 units. The stem, both rules and both gaps are all one stroke. The mark is 5 strokes wide and 6 tall, centred on the grid.

Clear space: keep 2s (half the mark's width) on every side. Nothing else goes inside the dashed line.

Small sizes

Real pixels, not scaled screenshots. The favicon file switches to the light version (and the lighter orange) when the browser is in dark mode.

Light mark with the orange rule on the cover green-black. The rounded file is for the web and desktop. The square “maskable” file is for Android and iOS, which cut their own shape: the dashed circle is Android's safe zone, and the mark sits well inside it.
